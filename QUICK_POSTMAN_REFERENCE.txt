## ❌ IF SOMETHING FAILS

### Error: "SMS not sent" or "401 Unauthorized"
- Check: `.env.local` has correct `TERMII_API_KEY`
- Check: Base URL is `https://v3.api.termii.com` (NOT old api.ng.termii.com)
- Check: Termii dashboard shows credits available

### Error: "Invalid phone number"
- Phone must be: `+2347015250000` or `2347015250000` or `07015250000`
- System auto-normalizes it

### Error: "Driver not found" (Test 3)
- Change `"from": "2347015250000"` to a real driver's phone in your database
- Check: Driver exists in users table with role='driver'

## 💬 QUICK HELP

**Can't find Postman tab?**
- VS Code → Extensions → Search "Postman"
- OR use VS Code REST Client extension
- OR use curl commands in terminal

**Backend won't start?**
- Check: `node -v` (need v18+)
- Check: `npm -v` 
- Check: All dependencies installed: `npm install`
- Check port 3000 is free

**API returns 500 error?**
- Check backend console for error message
- Check `.env.local` has all variables
- Check database is accessible

**Rate limiting?**
- Each test SMS costs credits
- Monitor: https://dashboard.termii.com → Wallet
- Plan: ~0.50-1.00 credit per SMS depending on length
